# Présentations

Matériel de présentation dérivé de la [base](../knowledge/README.md).

- [`_gabarit.md`](_gabarit.md) : gabarit de plan (public, durée, message clé, déroulé minuté, démonstration, sources, questions anticipées).
- Skill [`talk`](../.claude/skills/talk/SKILL.md) : génère un plan à partir d'un ou plusieurs chapitres ; dans Claude Code, `/talk` depuis la racine du dépôt.

Les plans générés sont enregistrés ici sous la forme `AAAA-MM-slug.md`.
