## Majeur

### L'équipe Claude Code formalise ses règles de vérification

- **Source** : [O] Osmani (équipe Claude Code), *How the Claude Code team thinks about verification*, 16/11/2026. <https://claude.dev/blog/how-the-claude-code-team-thinks-about-verification/>
- **Résumé** : les tests de bout en bout sont jugés les plus difficiles à tromper ; un contrôle qui échoue encore après trois tours fait intervenir un humain ; « If a change can modify the check that judges it, the check is broken » ; les règles de revue sont lues sur la branche de base, jamais dans la PR ; les tests instables ne peuvent être ni ignorés ni relancés jusqu'au vert.
- **Impact** : [chapitre 09](../../knowledge/09-verification-et-evaluation.md), section « La qualité des tests » (principe d'indépendance du capteur) et « Organiser la revue automatique » (lecture des règles depuis la branche de base). Cohérent avec le hook `verifier_fin`, qui exige une approbation de la commande, et avec le job de périmètre de la veille.

### Claude Code : skills fournis par des serveurs MCP et nouvel événement de hook

- **Source** : [O] Anthropic, *Claude Code v2.1.332* et *v2.1.329*, 19 et 25/11/2026. <https://github.com/anthropics/claude-code/releases/tag/v2.1.332>
- **Résumé** : v2.1.332 ajoute les skills exposés par des serveurs MCP (bêta, nommés `serveur:skill`) et un événement `PreSkillShellCommand` qui peut refuser la commande shell d'un skill ; v2.1.329 indique dans le dialogue de confiance où sont déclarés les hooks d'un dossier.
- **Impact** : [chapitre 05](../../knowledge/05-skills.md), état du débat « Skills ou serveurs MCP ? » (la convergence se concrétise) ; [chapitre 07](../../knowledge/07-hooks-et-garde-fous.md), tableau des événements ; [chapitre 10](../../knowledge/10-securite.md), couche « Confiance du dossier ».

### Bacs à sable externes pour agents de code

- **Source** : [P] Willison, *External sandboxes for coding agents*, 17/11/2026 (billet de lien vers un article de Prime Radiant, non lu). <https://simonwillison.net/2026/Nov/17/external-sandboxes-for-coding-agents/>
- **Résumé** : le code exécuté par l'agent tourne dans un bac à sable dédié tandis que l'agent reste à l'extérieur ; trois implémentations exposent la même API locale ; proxy HTTP en liste blanche et substitution des identifiants pour que l'agent ne détienne pas les secrets.
- **Impact** : [chapitre 10](../../knowledge/10-securite.md), section « Les couches de Claude Code » (alternative au bac à sable intégré, notamment sous Windows natif) ; [chapitre 12](../../knowledge/12-execution-autonome.md).
